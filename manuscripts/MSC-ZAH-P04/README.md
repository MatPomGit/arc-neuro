# MSC-ZAH-P04 — Odbiór rzeczywistych zachowań osób neuroróżnorodnych po przeniesieniu na syntetyczne awatary

**Właściciel naukowy i autor szkicu:** Mateusz Pomianek (`MatPomGit`). Współautorów należy wskazywać zgodnie z potwierdzonym wkładem; repozytorium kanoniczne jest odrębną informacją.

**Status:** `IDEA_HOLD`; prospektywna koncepcja. **Working title:** *Naturalistic Neurodivergent Social Behavior on Identical Avatars: Appearance-Dependent First Impressions*.

Czy rzeczywiste wzorce komunikacji osób o różnych profilach, odtwarzane na identycznych awatarach, wywołują odmienne pierwsze wrażenie zależnie od wyglądu postaci?

**H1:** Czasowe i przestrzenne właściwości naturalnie zarejestrowanej ekspresji komunikacyjnej są związane z ocenami pierwszego wrażenia przy kontrolowanej tożsamości awatara.

**H2:** Realizm wizualny moderuje związek między indywidualnym wzorcem zachowania a oceną niechęci i niesamowitości.

**Wynik główny:** Zależność ocen niechęci i niesamowitości od indywidualnych parametrów zachowania oraz realizmu postaci z uwzględnieniem kontekstu.

**Odrębność:** Naturalna neuroróżnorodność nie jest skalą mechaniczności ruchu. Badamy zachowania osób źródłowych, a nie profil neuroróżnorodności obserwatorów.
