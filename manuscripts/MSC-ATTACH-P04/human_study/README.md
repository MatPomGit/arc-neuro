# M04: prospective longitudinal human study

Status: draft only; not ready for recruitment. Migrated from the former M02 human-extension package on 2026-10-07 and assigned to the separate scale-to-behavior bridge. Psychometric item development and EFA/CFA remain in M03.

Phases: ecological-item comprehension and technical/burden feasibility pilot, then independent prospective ESM using a frozen defensible baseline scale. No pilot observations are silently pooled into confirmation. An optional partner module requires separate scope, private individual consent and a decision covering it. No default audio/video recording.
