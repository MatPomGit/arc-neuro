# Kontakt i wsparcie dla ARC Neuro

Repozytorium nie deklaruje dedykowanego zespołu wsparcia, SLA ani publicznego kanału poufnych zgłoszeń. Status tych funkcji: **NOT_CONFIGURED**.

Zgłoszenia dotyczące publicznej struktury programu mogą wskazywać dokładny commit SHA, ścieżkę, kryterium i zanonimizowany opis problemu. Nie przesyłaj przez otwarte Issue identyfikatorów projektów prywatnych, informacji klinicznych, danych uczestników ani sekretów.

Podejrzenie wycieku lub podatności przekazuj uprawnionemu właścicielowi poza publicznymi Issues; zobacz [SECURITY.md](SECURITY.md) i [procedurę incydentów](docs/security/incident-response.md). Decyzje naukowe i autorskie pozostają w kompetencjach właścicieli właściwych badań.
