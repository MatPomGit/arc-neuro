# Zasady zachowania

Prace nad ARC Neuro wymagają rzetelności naukowej, poszanowania godności uczestników, niedyskryminacji oraz ochrony informacji osobowych. Niedopuszczalne są nękanie, groźby, manipulowanie danymi, nieuzasadnione przypisywanie autorstwa i publikowanie cudzych materiałów bez zgody.

Uwagi w recenzjach powinny wskazywać konkretną hipotezę, wymaganie lub dowód. Niezgodności naukowe rozstrzygaj na podstawie metod, danych i źródeł, a nie oceny osób. Nie publikuj w GitHub Issues szczegółów podatności ani danych uczestników.

W razie naruszenia zgłoszenie należy skierować prywatnym, uprawnionym kanałem do właściciela programu lub właściwej instytucji. Repo nie deklaruje aktywnej infolinii ani gwarantowanego czasu reakcji. Zasady dostępu: [SECURITY.md](SECURITY.md).
