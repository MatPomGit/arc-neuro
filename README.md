# ARC Neuro

**Program badawczy:** `arc-neuro`  
**Opieka naukowa:** Mateusz Pomianek

ARC Neuro integruje badania nad poznaniem, afektem, neurorozwojem, zachowaniem społecznym i psychometrią. Głównym kryterium przynależności pracy jest pytanie badawcze dotyczące funkcjonowania człowieka, nie zaś samo zastosowanie określonej aparatury, sztucznej inteligencji czy rzeczywistości rozszerzonej.

## Obszary badań

| Obszar | Problematyka |
| --- | --- |
| Neurorozwój | Mechanizmy i zróżnicowanie rozwoju poznawczego |
| Afekt | Emocje, stres i regulacja afektywna |
| Poznanie | Uwaga, pamięć, funkcje wykonawcze i interakcja człowiek–AI |
| Zachowania społeczne | Relacje, przywiązanie i komunikacja |
| Psychometria | Rzetelność, trafność i interpretowalność pomiarów |

## Manuskrypty i projekty

[Katalog manuskryptów](manuscripts/catalog.json) określa identyfikatory, klasyfikację i stan prac. ## Metody i odtwarzalność

Badania wykorzystują metody statystyczne, modelowanie obliczeniowe, eksperymenty behawioralne i pomiary psychofizjologiczne. [Zakres naukowy](docs/scientific-scope.md) oraz [zasady odtwarzalności](REPRODUCIBILITY.md) opisują metodologię, związki z danymi i wymagania wobec dowodów. [Architektura](ARCHITECTURE.md) określa granice odpowiedzialności programu, a [zasady bezpieczeństwa](SECURITY.md) odnoszą się do ochrony zasobów.
