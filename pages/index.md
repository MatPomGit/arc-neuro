# ARC Neuro

**Program badań nad poznaniem, afektem i zachowaniem człowieka.**

ARC Neuro integruje interdyscyplinarne badania nad funkcjonowaniem człowieka, metodami pomiaru i analizą danych. Program obejmuje pięć powiązanych obszarów:

| Obszar | Problematyka |
| --- | --- |
| Neurorozwój | Różnice indywidualne i mechanizmy neurorozwojowe |
| Afekt | Emocje, stres oraz regulacja afektywna |
| Poznanie | Uwaga, pamięć, funkcje wykonawcze i interakcja człowiek–AI |
| Zachowania społeczne | Relacje interpersonalne, przywiązanie i komunikacja |
| Psychometria | Trafność, rzetelność i interpretowalność pomiaru psychologicznego |

## Podejście naukowe

Badania wykorzystują m.in. modelowanie statystyczne i uczenie maszynowe, eksperymenty behawioralne, pomiary psychofizjologiczne i narzędzia komputerowe. O przynależności pracy do programu decyduje **pytanie badawcze**, a nie tylko wykorzystywana technologia.
