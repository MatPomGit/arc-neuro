# Rejestr decyzji architektonicznych ARC Neuro

ADR opisują wybory techniczne i ich alternatywy, nie zastępują [rejestru decyzji programu](../decisions.md) ani stanu badań.

| ADR | Zakres | Status |
| --- | --- | --- |
| [0001](0001-ownership-boundaries.md) | Własność pracy, aplikacji i kodu | proposed |
| [0002](0002-publication-boundaries.md) | Rejestry i granica publicznych Pages | proposed |
| [0003](0003-issue-autonomy-boundaries.md) | Issues/JUMP, klasyfikacja i brak samodzielnego dispatch | proposed |

Zatwierdzony ADR wymaga odrębnego wpisu decyzji właściciela. Dokument `proposed` nie potwierdza wdrożenia. Zmiany rejestrowe i publikacyjne podlegają dodatkowym bramkom [GOVERNANCE.md](../../GOVERNANCE.md).
