# Reagowanie na incydenty ARC Neuro

Jeżeli publiczne repozytorium, strona lub jej artefakty ujawniają prywatny identyfikator projektu, dane uczestnika, nagrania, sekret lub wewnętrzny dokument, przerwij tylko własny niebezpieczny eksport i **powiadom uprawnionego właściciela prywatnym kanałem**. Nie wklejaj szczegółów do otwartego Issue, komentarza PR lub artefaktu CI.

Zabezpiecz niezbędne dowody (URL, czas, exact SHA, zakres ekspozycji) w odpowiednio chronionej lokalizacji. Właściciel określa konieczność rotacji poświadczeń, wycofania witryny, oczyszczenia artefaktów i właściwych powiadomień. Zmiana aktualnego źródła nie usuwa historycznych kopii i pamięci podręcznych.

Dla problemu dotyczącego uczestników badań zastosuj również właściwe instytucjonalne procedury etyczne i ochrony danych. Wykonanie naprawy i jej weryfikacja są oddzielnymi etapami; odnotuj rzeczywisty rezultat, nie deklarację.

Bez poufnego kanału zgłoszeniowego stan organizacyjny pozostaje `NOT_CONFIGURED`. Zobacz [SECURITY.md](../../SECURITY.md).
