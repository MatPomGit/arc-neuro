# Zasady zarządzania programem

Przyjmuj tylko projekty z kanonicznym właścicielem, repozytorium, poprawnym zakresem i określonym statusem dowodowym. Ogranicz liczbę otwartych PR do obowiązujących limitów projektu. Zmiany przypisania manuskryptu, publikowanie danych, reorganizacje historii Git, przenoszenie repozytoriów i rozszerzanie uprawnień wymagają osobnej decyzji. GitHub Pages prezentuje wyłącznie zatwierdzone publiczne metadane naukowe.


Autorstwo repozytorium programu obejmuje zawsze Mateusza Pomianka; inni współautorzy są opcjonalni po potwierdzeniu rzeczywistego wkładu. Osobno rozstrzyga się autorstwo poszczególnych artykułów w kanonicznych projektach `msc-*`.
