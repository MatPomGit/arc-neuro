# Kontrakt reprodukowalności ARC Neuro

Każdy publiczny wpis musi wskazywać jednego właściciela naukowego i repozytorium kanoniczne, oznaczać fazę badań oraz podawać rzeczywiste dowody. `snapshot_sha` pozostaje nieruchomą migawką używaną do odtworzenia; `remote_head_sha` jest niezależnym stanem do audytu świeżości. Syntetyczne testy struktury nie są pomiarem naukowym.

Publiczny rekord nie może samoistnie promować pracy z `planned` na `submitted` lub `published`; przejście wymaga źródeł, DOI, dowodu zgłoszenia albo rzeczywiście opublikowanego artykułu. Dokumenty `REPRODUCIBILITY.md` i `RESEARCH.md` określają metodologiczne szczegóły.

Prywatne pomiary, surowe dane i niejawne mapowania 63 slotów pozostają u uprawnionych właścicieli, poza publicznym ARC. Ustalona procedura odtwarzania wykorzystuje przypięty commit i realnie dostępne pakiety, nie przypadkową wersję HEAD.
