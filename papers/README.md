# Katalogi robocze artykułów ARC Neuro

W katalogu przygotowano **63 neutralne miejsca robocze** w pięciu liniach badawczych. Są to wyłącznie struktury organizacyjne, **nie** gotowe ani zatwierdzone manuskrypty i nie publiczny rejestr planowanych publikacji.

| Linia badawcza | Katalog | Miejsca |
| --- | --- | ---: |
| Neurorozwój i neuroróżnorodność | [ndd](ndd/README.md) | 16 |
| Afekt i regulacja emocji | [affect](affect/README.md) | 4 |
| Poznanie i interakcja człowiek–AI | [cognition](cognition/README.md) | 13 |
| Relacje i zachowania społeczne | [social](social/README.md) | 22 |
| Psychometria i metody pomiarowe | [psychometrics](psychometrics/README.md) | 8 |

Nazwy `slot-NNN` są neutralnymi identyfikatorami katalogów, **nie** identyfikatorami MSC ani numerami publikacji. Kanoniczne powiązanie każdego katalogu z manuskryptem jest zapisane wyłącznie w prywatnym `MatPomGit/research-autopilot`, w `neuro_paper_slots.csv`. Tytuły, statusy prac, hipotezy, autorzy i repozytoria źródłowe pozostają we właściwych repozytoriach badawczych.

`portfolio/papers.json` i `portfolio/projects.json` są niezależnym, publicznym katalogiem wymagającym indywidualnego zatwierdzenia wpisu. Utworzenie katalogu roboczego **nie** oznacza zgody na ujawnienie prywatnych informacji ani aktywacji GitHub Pages.

Artefakty instrumentów i prac dyplomowych nie są kolejnymi artykułami. Nie umieszczać w tych folderach surowych danych, manuskryptów z niezweryfikowanymi prawami ani kopii repozytoriów `msc-*`.
