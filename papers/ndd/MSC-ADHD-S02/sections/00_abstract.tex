\abstract{Adaptive serious games increasingly use event telemetry to reconstruct player state, trigger interventions, and evaluate change over time. Yet a log sufficient for application debugging is not necessarily sufficient for scientific reconstruction. This methods paper specifies a versioned challenge--regulation--recovery event representation designed to preserve causal ordering, measurement context, missingness, censoring, intervention configuration, and controller decisions required for reproducible analysis. The schema separates descriptive events from derived inferences, distinguishes missing telemetry from non-recovery, uses monotonic within-session timing, and records the exact reference state and feature-model version used to determine recovery. A reference implementation includes JSON Schema validation, deterministic controller replay, queue semantics, and unit tests for valid and invalid event sequences. The contribution is a reproducibility contract for adaptive serious-game telemetry rather than evidence of therapeutic efficacy.}
