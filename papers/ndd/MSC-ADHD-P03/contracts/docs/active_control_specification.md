# ARC-ADHD active-control specification

Status: core pilot design specification.

The active control is intended to control for time, attention, digital-game exposure, reward, novelty and private-phone use without reproducing the hypothesized challenge-regulation-recovery mechanism.

## Design objective

The active control should answer:

> Is the ARC-ADHD closed-loop recovery sequence associated with additional change beyond an engaging, credible, time-matched digital game?

It is not intended to be an inert wait-list.

## Matched properties

The control should match the ARC-ADHD core condition as closely as practical on:

- total prescribed session duration;
- number of sessions and intervention period;
- study contact and onboarding;
- the same BYOD compatibility/qualification policy and device-capability capture;
- visual production quality;
- general reward density;
- neutral performance feedback;
- approximate amount of touchscreen interaction;
- age-appropriate narrative framing;
- caregiver contact required for logistics;
- data-collection schedule.

## Properties that must not be reproduced

The active control must not systematically implement:

- controlled challenge followed by an explicit regulation transition;
- pause → orient → strategy → regulate → recover → resume-goal training;
- individualized recovery-latency feedback;
- explicit practice of regulation strategies after challenge;
- adaptation based on recovery state;
- implementation-intention prompts linking recovery strategies to everyday situations.

If these elements are present, the comparison no longer isolates the proposed mechanism.

## Candidate control content

A suitable control can use short, engaging tasks such as:

- age-appropriate visual search;
- simple knowledge or categorization games;
- non-adaptive puzzles;
- pattern matching;
- low-demand reaction games;
- narrative progress tasks.

Difficulty can remain within a comfortable range to maintain engagement, but it should not be adapted according to the ARC-ADHD recovery model.

## Sensory matching

Visual presentation should be comparable in quality. Ordinary sound and haptic feedback may be included when needed to prevent obvious group identification, provided they are not arranged as the experimental regulation cues.

Bilateral auditory stimulation, camera-derived facial feedback and AR/embodied companion modules are excluded from both arms of the core pilot unless a later protocol explicitly integrates them.

## Credibility and expectancy

Before meaningful exposure, caregivers and children should rate expected usefulness/credibility using an age-appropriate procedure. The goal is to detect large expectancy imbalance, not to prove successful participant blinding.

The control should be described using neutral language and should not be labelled as a placebo, sham or inferior intervention in participant-facing materials.

## Contamination checks

Telemetry and post-study questioning should assess whether the control unintentionally contains:

- spontaneous pause/regulation coaching;
- caregiver-delivered regulation instruction prompted by the control;
- repeated challenge-recovery sequences similar to ARC-ADHD;
- access to core training materials outside the assigned condition.

## Fidelity record

For both arms, archive:

- software version;
- task list;
- session schedule;
- reward configuration;
- sensory configuration;
- adaptation rules;
- caregiver instructions;
- deviations and outages.

The control should be version-locked at the same study gate as the intervention.
