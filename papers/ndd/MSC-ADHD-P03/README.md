# MSC-ADHD-P03 — Wpływ obustronnej stymulacji słuchowej na regulację

**Właściciel naukowy i autor szkicu:** Mateusz Pomianek (`MatPomGit`). Nie ustalono dodatkowych współautorów.

W katalogu [`papers/catalog.json`](../../catalog.json) pozycja ma rodzaj `MANUSCRIPT` i etap `ACTIVE`. Jest to **status prac nad szkicem**, nie dowód rozpoczęcia badania z udziałem ludzi, uzyskania wyników ani publikacji.

[Plik LaTeX](main.tex) przedstawia projekt pilotażu porównującego naprzemienną stymulację słuchową z kontrolą akustyczną o zrównanej głośności. Proponowaną miarą jest czas wznowienia zadania po zakłóceniu. Definicja wskaźnika, protokół, hipotezy i analiza wymagają doprecyzowania przed rekrutacją.

Nie wykazano w tym katalogu zbioru danych, wyników, zweryfikowanej bibliografii, prerejestracji, zgody etycznej ani wykonanej kompilacji. Nie przeprowadzono uwierzytelnionego audytu `audit-live`; status zewnętrznych dowodów jest `UNAVAILABLE`.

**Granica własności:** `arc-neuro` jest publicznym indeksem i zawiera roboczy szkic `main.tex`. Kanonicznego repozytorium projektu, jego `project_id` i repozytorium źródłowych dowodów nie potwierdzono w pustych rejestrach `portfolio/projects.json` i `portfolio/papers.json`. Nie wolno na tej podstawie przypisać praw do cudzych materiałów ani kopiować innych manuskryptów. Przypisanie kanoniczne wymaga osobnej weryfikacji.
