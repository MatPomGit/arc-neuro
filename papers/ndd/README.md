# Neurorozwój i neuroróżnorodność

Ten obszar zawiera **16 neutralnych katalogów roboczych** artykułów programu ARC Neuro. Foldery mają wyłącznie identyfikatory `slot-NNN`; ich powiązanie z identyfikatorami MSC znajduje się w prywatnym rejestrze planistycznym Research Autopilot.

Katalogi nie stanowią publicznego rejestru zatwierdzonych publikacji. Zasady i indeks wszystkich obszarów: [katalog artykułów](../README.md).
